# ClassTrack

## [▶ Open ClassTrack](https://ahinnewton.github.io/classtrack/?v=accounts-20261112-2)

**Click “Open ClassTrack” above to use the app.** This GitHub page contains its source files.

Create an account with a username and password—no email required. Your classrooms and participation records save to your account. The student directory includes 90 students organized by grade.

[Direct link to the account app](https://classtrack-participation-ahin.songhui.chatgpt.site/)

Access to the account app follows its private sharing settings. If you see a permission page, use the ChatGPT account that owns ClassTrack or request access.

The live app checks for new versions when opened or revisited. Updates load automatically when there are no unsaved changes; otherwise an Update button appears.

The previous fictional-sample demo remains at [demo.html](https://ahinnewton.github.io/classtrack/demo.html). Its local browser records are preserved. No real student roster or private account data is stored in this public repository.
